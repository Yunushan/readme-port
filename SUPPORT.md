# Support

Use the right channel so questions remain useful to future readers:

- Setup or behavior question: open a discussion if enabled, otherwise a support issue.
- Reproducible defect: use the bug report form.
- New template or provider enhancement: use the feature request form.
- Vulnerability: follow [SECURITY.md](SECURITY.md); never post exploit details publicly.

Please include your Node.js version, operating system, provider, render mode, template ID, command, and the smallest safe configuration that reproduces the problem.
