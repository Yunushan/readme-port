# Security policy

## Supported versions

Security fixes are applied to the latest released major version.

## Reporting a vulnerability

Use GitHub private vulnerability reporting when it is available for this repository. If it is not available, open a minimal issue asking a maintainer for a private reporting channel; do not include exploit details, secrets, or personal data in that issue.

Include the affected command or component, impact, reproduction conditions, and a suggested mitigation when possible. You should receive an acknowledgement within seven days.

## Security model

ReadmePort does not need account credentials or forge API tokens. The browser Studio runs locally, stores configuration in the browser, and has no analytics. Configurations and templates are still untrusted input: review generated links and external images before publishing them.
