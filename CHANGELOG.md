# Changelog

All notable changes to ReadmePort are documented here. The project follows semantic versioning.

## 1.0.0 - 2026-07-12

### Added

- Seven editable project, profile, and organization templates.
- Portable and provider-aware output for GitHub, GitLab, Gitea, Forgejo, and Bitbucket Cloud.
- Zero-runtime-dependency Node.js CLI with `init`, `build`, `check`, `validate`, `doctor`, `eject`, `list`, and `serve` commands.
- Local-only browser Studio with live configuration, preview, import, and export.
- Manual regions that survive regeneration.
- JSON Schema, four themes, generated examples, multi-forge CI definitions, and community templates.
- MIT license and original SVG branding assets.
